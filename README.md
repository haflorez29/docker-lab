# Docker Lab Practice

This repository is a set of Docker practice projects created to learn containerization and orchestration.

It includes:

- `1.init/`: Docker exercises for NestJS, GraphQL, MongoDB, PostgreSQL, and Docker Compose.
- `2.create-image/`: A simple Node.js project to build and publish a Docker image.

The repo is designed to be easy to review, with practical commands and clear examples of:

- manual Docker container execution
- Docker Compose service orchestration
- persistent volumes
- Docker networks
- using images and ports

Use this repository as a reference for Docker learning and hands-on practice.
