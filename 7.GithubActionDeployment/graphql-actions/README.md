## Practice notes

This lab used an existing NestJS project and added a simple CI/CD flow with GitHub Actions and Docker Hub.

### What was done

- The project code was added to a GitHub repository.
- A Docker Hub repository was created.
- A Docker Hub access token was generated.
- Two GitHub secrets were added:
  - `DOCKER_NAME`: Docker Hub username
  - `DOCKER_PASSWORD`: Docker Hub access token
- The image was built and tested locally:

```bash
docker build -t heidyxp/docker-graphql:0.0.1 .
docker container run -p 3000:3000 heidyxp/docker-graphql:0.0.1
```

- A workflow file was created in `.github/workflows/docker-image.yml` to run the CI/CD steps.
- The semantic versioning GitHub Action was added from the Marketplace.

### How to repeat this lab

1. Start with a precreated NestJS project.
2. Add the code to GitHub.
3. Create a Docker Hub repository and generate an access token.
4. Add the Docker Hub credentials as GitHub secrets.
5. Build and test the image locally.
6. Create the workflow file and connect it to the repository.
7. Use semantic versioning based on the version in `package.json`.
